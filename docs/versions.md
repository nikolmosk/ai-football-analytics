# Version roadmap

## v0.2.0
Live odds provider foundation.

## v0.3.0
PostgreSQL, SQLAlchemy, Alembic, matches and odds persistence.

## v0.4.0
Competitions, seasons, teams and normalized match ingestion.

## v0.5.0
Production ingestion from The Odds API with bookmaker snapshots.

## v0.6.0
Odds history and line movement.

## v0.7.0
Market normalization and bookmaker comparison.

## v0.8.0
Poisson model connected to stored match data.

## v0.9.0
Dixon-Coles model.

## v0.10.0
Core markets: 1X2, totals, BTTS.

## v0.11.0
Fair odds, de-vig, edge and EV.

## v0.12.0
No-bet gates, uncertainty and data-quality scoring.

## v0.13.0
Walk-forward backtesting.

## v0.14.0
Calibration metrics and reliability diagnostics.

## v0.15.0
Authentication and user accounts.

## v0.16.0
Android-oriented API, pagination and stable DTOs.

## v0.17.0
Redis and background ingestion workers.

## v0.18.0
Structured AI explanation layer.

## v0.19.0
Observability, integration tests and Docker hardening.

## v0.20.0
Backend MVP consolidation and release candidate.
